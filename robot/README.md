# Базовый шаблон проекта робота (XHE RPAbot)

## Описание

Это базовый шаблон для создания RPA-роботов на платформе XHE. Шаблон содержит стандартную структуру проекта и необходимые файлы для быстрого начала разработки.

## Начало работы

### 1. Настройка окружения

Убедитесь, что у вас установлена платформа XHE.

### 2. Заполнение паспорта робота

Отредактируйте файл `passport.json`:

```json
{
  "UniqueKey": "УНИКАЛЬНЫЙ_ID_РОБОТА",
  "RobotName": "Название робота",
  "DeveloperName": "Ваше Имя Фамилия",
  "DateTimeCreation": "2025-12-01T00:00:01.0+03:00",
  "DateTimeChanges": "2025-12-01T23:59:59.0+03:00",
  "DeveloperComments": "Ссылка на документацию"
}
```

### 3. Настройка параметров

Отредактируйте `settings/settings.json`:

- **mailerType**: Тип почтового клиента
- **smtpServer/imapServer**: Настройки почтовых серверов
- **mode**: Режим работы (demo/prod)
- **robotID**: Идентификатор робота
- **proxy**: Настройки прокси (если необходимо)

### 4. Основные настройки в run.php

Проверьте и измените при необходимости:

```php
// Адрес XHE API
$xhe_host = getenv("RPABOT_HOST_URL");

// Часовой пояс
date_default_timezone_set('Europe/Moscow');

// Уровень логирования (1-4)
$log_level = 1;

// Тип остановки
$appQuitType = "quit"; // quit, exitapp, restart_and_quit
```

## Запуск робота

### Через командную строку

```bash
php run.php
```

### Через XHE

Откройте файл `run.php` в среде XHE и нажмите "Запуск".

## Логирование

Логи сохраняются в папку `log/` с именем вида `log_ГГГГ-ММ-ДД.log`.

Уровни логирования:
- **1** - DEBUG (отладка)
- **2** - INFO (информация)
- **3** - WARN (предупреждения)
- **4** - ERROR (ошибки)

## Рекомендации по разработке

1. **Храните данные** в папке `data/`
2. **Сохраняйте результаты** в папке `res/`
3. **Используйте временные файлы** в папке `temp/`



## 🛠️ Скиллы (Skills)

Все действия выполняются через вызов скиллов, маршрутизируемых через `.agents/skills/INDEX.md`
