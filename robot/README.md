# Робот сбора объявлений auto.ria

Робот для [Human Emulator Studio 7.x]: обходит доску объявлений
[auto.ria.com](https://auto.ria.com), открывает только те, которых ещё не
видел, и складывает их в файл. Фильтры ваши — робот повторяет адрес
страницы, который вы скопировали.

## Что нужно

- Human Emulator Studio 7.x (движок Chromium).
- Больше ничего: ни composer, ни npm, ни pip.

## Как запустить

1. Откройте папку с роботом как проект в Studio.
2. Впишите свои задачи в `run.php` (см. ниже).
3. Запустите `run.php`.

Из консоли `php run.php` **не работает**: обращения к браузеру — это HTTP к
запущенной Studio, и без неё падает всё. Правила проекта: `AGENTS.md`.

## Задачи

Задача — это адрес, который вы скопировали с доски: открыли её руками,
отфильтровали (марка, модель, город, цена), скопировали адрес. Фильтры
остаются в ссылке, поэтому робот не угадывает, а повторяет ваш выбор.

```php
$autoriaBoards = [
    [
        'name' => "auto.ria — BMW",
        'url'  => "https://auto.ria.com/car/bmw",
        'file' => __DIR__ . "/data/autoria_bmw.xlsx",
    ],
    [
        'name' => "Киев, до 5000 $",
        'url'  => "https://auto.ria.com/car/used/?pricefrom=1000&priceto=5000",
        'file' => __DIR__ . "/data/kyiv_5000.xlsx",
    ],
];
```

Поля задачи:

| Поле | Обязательно | Что значит |
|---|---|---|
| `name` | да | Как задача называется в логе |
| `url` | да | Адрес выдачи с фильтрами |
| `file` | нет | Куда положить результат; из `name` сделается свой |
| `onlyNew` | нет | Только новые. По умолчанию `true` |
| `limit` | нет | Сколько максимум. По умолчанию 100 |
| `pages` | нет | Сколько страниц выдачи обойти. По умолчанию 3 |

Если `file` не указать, имя файла получится из `name` — кириллица в имени
сохраняется, так что «Киев, до 5000» станет `Киев_до_5000.xlsx`.

Задача, которая не отработала, не отменяет остальные: ошибка попадёт в
лог, обход пойдёт дальше.

## Почему страниц несколько

**У auto.ria нет сортировки по новизне.** В разметке нет ни параметра
сортировки, ни переключателя порядка — только фильтры «Все / Б/у / Новые /
Под пригон». Порядок объявлений на странице марки задаёт доска.

Поэтому одной страницы мало: новое объявление может на ней не появиться,
робот его пропустит, а это выглядит как «новых объявлений нет». Робот
обходит `$autoriaPages` страниц подряд — по умолчанию 3, по 20 объявлений
на странице.

Это недорого: объявления, которые уже отдавали, повторно не открываются,
поэтому каждый запуск платит только за загрузку списков. Если доска
большая, а проверки редкие — поставьте больше.

## Формат файла

Расширение задаёт формат: `.csv` или `.xlsx`.

По умолчанию `.csv`, и это не случайно: **отчёт накапливается** — каждый
запуск дописывает найденное в конец, а не затирает предыдущие строки. CSV
умеет дописывать, а xlsx нет: его писатель каждый раз создаёт файл заново,
поэтому в `.xlsx` попадёт только содержимое последней проверки.

Нужен именно Excel — допишите `.xlsx`, но тогда храните отчёты по одному
файлу на запуск, иначе предыдущие результаты пропадут.

Кириллица в CSV нормальная: файл пишется в UTF-8 с меткой порядка байтов,
поэтому Excel открывает его сразу, без импорта.

## Что в файле

`url`, `title`, `price`, `currency`, `mileage_km`, `city`, `brand`, `model`,
`year`, `vin`, `body_type`, `color`, `fuel`, `transmission`, `seller`.

Телефон сюда **не входит и не должен**: условия площадки прямо запрещают
автоматический сбор номеров телефонов (п. 1.21 оферты
[ria.com/offert/auto](https://www.ria.com/offert/auto/)). В `run.php` есть
настройка `$collectPhones`, но включать её можно только имея письменное
согласие RIA. Продавать продукт, который это нарушает, нельзя.

## Что означает «новое»

Объявление новое, если его ещё нет в `data/autoria_state.json`. Даты
публикации на доске нет вообще, поэтому ориентироваться не на что.
Файл состояния в репозиторий не попадает — это ваши локальные данные.

## Расписание

По умолчанию робот регистрирует себя в планировщике Studio
(`WINDOW::$scheduler`) — задача создаётся один раз, а при повторных
запусках обновляется, а не плодится. Интервал задаётся `$scheduleInterval`
в `run.php`.

Осторожно: планировщик Studio умеет не все интервалы. Точно работают
минута, 5, 10 и 30 минут, час, сутки и неделя. Если выбрано что-то другое
(например 2 часа), задача не создаётся, а в лог пишется объяснение —
робот не станет молча проверять доску чаще, чем вы просили. Свой интервал
можно задать через Планировщик Windows, тогда `$scheduleRegisterOnRun`
надо поставить в `false`.

## Если что-то не работает

- **Пустой файл или 0 объявлений.** Проверьте адрес: открывается ли он
  руками и есть ли на нём карточки. Если адрес верный, а робот молчит —
  доска поменяла вёрстку, см. `AGENTS.md` раздел про локаторы.
- **Локатор перестал работать.** Класс карточек и разметка задаются в
  `AutoriaListingsScraper`. Сначала откройте страницу и посмотрите, что
  в ней реально, и только потом правьте константы.
- **Лог.** `log/log_ГГГГ-ММ-ДД.log`. Ошибки и предупреждения о том, что
  не сошлось, пишутся туда же.
- **Проверка без доски.** `php tests/tests.php` — правила, телефоны,
  даты, колонки, интервалы. Studio и браузер не нужны.

## Условия и ограничения

- Сбор данных объявлений auto.ria условиями **разрешён**; `robots.txt` для
  общих агентов страницы выдачи и объявления не запрещает.
- Сбор **номеров телефонов** условиями **запрещён** — см. выше.
- rst.ua не поддерживается: сайт закрыт Cloudflare Turnstile, обход стоит
  денег или вовсе не проходит. Подробности в `AGENTS.md`.
- OLX запрещает scraping в своих условиях. На нём этот робот не работает.
